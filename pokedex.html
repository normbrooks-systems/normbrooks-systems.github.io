What's actually interesting.

On its surface this is a damage calculator. Underneath, the question I was poking at was: how do you write a lookup table once, and have every other sheet in the workbook query it by name without knowing anything about its shape?

The answer in production is schema-abstracted named ranges and a small dispatch layer that resolves type → column index at query time rather than at write time. Add a 19th type to the chart and nothing downstream has to be rewritten. That same pattern shows up in every analytics tool I've shipped — the operational dashboards at Innovairre lean on a more elaborate version of it.

The full version covers 893 Pokémon and resolves dual-type defenders via product multiplication. This demo runs the same logic over an 18×18 type chart and a curated sample list.
